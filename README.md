# ☀️ Casa Sunshine — Interactive Interior Design Board

An interactive interior design showcase for **Casa Sunshine**, a vacation rental property located in St. Augustine, Florida.

This project presents the property's interior redesign through photorealistic visualizations, before-and-after comparisons, interactive 360° room tours, and curated furniture and décor shopping lists.

## Features

- **Room-by-room design boards** — Explore the living room, dining room, and bedrooms.
- **Interactive 360° tours** — Experience immersive panoramic views of the redesigned spaces.
- **Clickable shopping hotspots** — Discover furniture and décor through interactive product markers.
- **Before & After** — Compare the original interiors with the proposed
